NFL In-Game Win Probability with Tree-Based Models

Lecture 2 tutorial sequence

Author

Hua Gong

1 Overview

This sequence develops an NFL in-game win-probability model from a logistic-regression baseline through modern tree ensembles. One modeling problem, one data definition, and one evaluation design are used throughout so that differences in performance can be attributed to the models rather than to changing data pipelines.

The central prediction is

P(home team eventually wins∣current game state). P(\text{home team eventually wins}\mid\text{current game state}).

The response equals 1 when the home team eventually wins and 0 otherwise. Every predictor must be known at the moment of prediction.

3 Data

The local file data/nfl_wp_states.rds is generated from 2022 and 2023 regular-season play-by-play data distributed through nflreadr. To keep classroom computation manageable, the preparation script retains one eligible state per game per two-minute block of regulation.

library(dplyr)

nfl_states <- readRDS("data/nfl_wp_states.rds")

nfl_states %>%
  summarize(
    states = n(),
    games = n_distinct(game_id),
    seasons = paste(sort(unique(season)), collapse = ", "),
    home_win_rate = mean(home_win)
  )
# A tibble: 1 × 4
  states games seasons    home_win_rate
   <int> <int> <chr>              <dbl>
1  16581   541 2022, 2023         0.558
Note

This is a teaching sample, not a production win-probability data set. A production system should retain every eligible state, document data latency, address overtime explicitly, and monitor rule and strategy changes across seasons.

6 Modeling rules used throughout

  1. Use 2022 for model development and leave 2023 untouched until final evaluation.
  2. Assign all states from the same game to the same resample.
  3. Fit preprocessing steps using training data only.
  4. Use Brier score and log loss as primary metrics.
  5. Examine calibration, not only ranking or classification accuracy.
  6. Compare every complex model with the logistic baseline.
