# NFL win-probability teaching data

`nfl_wp_states.rds` is generated by `R/prepare_nfl_wp_data.R` from the
2022 and 2023 regular-season play-by-play files distributed through the
[`nflreadr`](https://nflreadr.nflverse.com/) package.

For manageable classroom computation, the script retains the first eligible
pregame state in each two-minute block of regulation. It excludes tied final
games, overtime states, and observations missing required predictors. The
response `home_win` equals 1 when the home team eventually won.

The data set is intended for classroom teaching rather than production modeling.
Students should cite both `nflreadr`/`nflverse` and the relevant upstream data
provider when publishing an analysis.
