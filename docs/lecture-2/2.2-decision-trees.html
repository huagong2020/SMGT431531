2.2 Classification and Regression Trees (CART)

Author

Hua Gong

1 Learning objectives

After completing this tutorial, you should be able to:

  1. calculate classification impurity and regression squared error;
  2. explain greedy recursive partitioning;
  3. distinguish classification-tree and regression-tree predictions;
  4. derive the score used to select a split;
  5. use cost-complexity pruning and tuning parameters to control overfitting; and
  6. fit and evaluate CART models in R.

2 The CART idea

A decision tree repeatedly divides the predictor space into regions. Within each terminal region, the model makes one constant prediction.

Every internal node asks one yes/no question about a single predictor. Every path from the root down to a leaf is a chain of those questions joined by “and”, and the leaf at the end of that path is one region RmR_m. A tree with MM leaves therefore writes its prediction as

f̂(x)=∑m=1Mcm𝟏(x∈Rm), \hat f(x)=\sum_{m=1}^{M}c_m\,\mathbf 1(x\in R_m),

where exactly one indicator is ever equal to one. In the diagram above,

R1={home_score_diff<0}∩{minutes_remaining<10}, R_1=\{\text{home\_score\_diff}<0\}\cap\{\text{minutes\_remaining}<10\},

and a state falling in R1R_1 receives the prediction c1c_1 no matter where inside R1R_1 it sits. The regions do not overlap and together they cover the whole predictor space.

For classification, a leaf predicts class probabilities. For regression, a leaf predicts the mean response. The tree is interpretable because every prediction follows a sequence of if/then rules.

3 Impurity for classification trees

For node RR with class proportions p1R,…,pKRp_{1R},\ldots,p_{KR}, Gini impurity is

G(R)=1−∑k=1KpkR2. G(R)=1-\sum_{k=1}^{K}p_{kR}^2.

For a binary outcome with home-win proportion pRp_R,

G(R)=2pR(1−pR). G(R)=2p_R(1-p_R).

Entropy is an alternative:

H(R)=−∑k=1KpkRlog⁡(pkR). H(R)=-\sum_{k=1}^{K}p_{kR}\log(p_{kR}).

A candidate split ss divides a parent node RR into children RleftR_{\mathrm{left}} and RrightR_{\mathrm{right}}. Its improvement is

ΔI(s,R)=I(R)−nleftnI(Rleft)−nrightnI(Rright), \Delta I(s,R) =I(R)-\frac{n_{\mathrm{left}}}{n}I(R_{\mathrm{left}}) -\frac{n_{\mathrm{right}}}{n}I(R_{\mathrm{right}}),

where nn is the number of observations in the parent node, and nleftn_{\mathrm{left}} and nrightn_{\mathrm{right}} are the numbers in the left and right children.

At a node, CART evaluates the allowable variable-threshold pairs and chooses

s*=arg⁡maxsΔI(s,R). s^*=\arg\max_s \Delta I(s,R).

This is a greedy choice: CART selects the best split now without searching over all possible future trees. The greedy strategy is computationally practical, but it does not guarantee the globally optimal tree.

gini <- function(y) {
  p <- mean(y)
  2 * p * (1 - p)
}

root_gini <- gini(hand_example$home_win)
left_gini <- hand_example %>%
  filter(home_score_diff > 0) %>%
  pull(home_win) %>%
  gini()

  filter(home_score_diff <= 0) %>%

weighted_child_gini <- (4 / 6) * left_gini + (2 / 6) * right_gini

5 How recursive partitioning builds a tree

Starting with all training observations in the root node, CART repeats the following operations:

  1. Generate candidate splits for every eligible predictor.
  2. Calculate ΔI(s,R)\Delta I(s,R) for every candidate.
  3. Select the candidate with the largest reduction in impurity.
  4. Send observations to the two child nodes.
  5. Repeat within each child until a stopping rule is reached.

For a binary classification leaf RR, the raw probability estimate is

p̂R=1nR∑i:xi∈Ryi. \hat p_R=\frac{1}{n_R}\sum_{i:x_i\in R}y_i.

An optional Laplace-smoothed estimate is

p̃R=n1R+anR+2a, \tilde p_R=\frac{n_{1R}+a}{n_R+2a},

where n1Rn_{1R} is the number of wins and a>0a>0 is a smoothing constant. With two losses and a=1a=1, the raw estimate is 0 but the smoothed estimate is 1/(2+2)=.251/(2+2)=.25. The rpart probabilities shown in this tutorial are the raw leaf proportions; the smoothing formula explains one way to reduce extreme estimates in small leaves.

6 Regression trees

For a continuous response, a node predicts its mean:

ŷR=1nR∑i:xi∈Ryi. \hat y_R=\frac{1}{n_R}\sum_{i:x_i\in R}y_i.

CART chooses the split that produces the largest reduction in squared error:

SSE(R)=∑i:xi∈R(yi−y‾R)2. SSE(R)=\sum_{i:x_i\in R}(y_i-\bar y_R)^2. 

regression_example <- hand_example %>%
  mutate(final_margin = c(12, 8, 5, -2, -6, -10))

root_sse <- sum(
  (regression_example$final_margin - mean(regression_example$final_margin))^2
)

split_sse <- regression_example %>%
  mutate(node = home_score_diff > 0) %>%
  group_by(node) %>%
  summarize(
    node_sse = sum((final_margin - mean(final_margin))^2),
    .groups = "drop"
  ) %>%
  summarize(total = sum(node_sse)) %>%
  pull(total)

tibble(

8 Cost-complexity pruning

For tree TT, cost-complexity pruning minimizes

Rα(T)=R(T)+α|T|, R_\alpha(T)=R(T)+\alpha|T|,

where R(T)R(T) is training loss, |T||T| is the number of terminal nodes, and α\alpha penalizes complexity.

For any fixed α\alpha, a larger tree is retained only when its reduction in training loss is large enough to pay the penalty for its additional leaves. Increasing α\alpha therefore produces a nested sequence of smaller subtrees.

rpart reports its own cross-validated error in the xerror column, and it is tempting to prune at cp with the smallest xerror. Do not do that here. rpart cross-validates by splitting rows at random, which is exactly the leakage Tutorial 2.1 warns against: states from one game land in both the training and held-out folds, and the resulting xerror is optimistic.

Select the complexity on whole validation games instead.

candidate_cp <- unique(classification_tree$cptable[, "CP"])

cp_search <- lapply(candidate_cp, function(cp_value) {
  candidate_probability <- predict(
    prune(classification_tree, cp = cp_value),
    newdata = validation_data,
    type = "prob"
  )[, "win"]

  tibble(
    cp = cp_value,
    leaves = sum(
      prune(classification_tree, cp = cp_value)$frame$var == "<leaf>"
    ),
    log_loss = log_loss(validation_data$home_win, candidate_probability)
  )
}) %>%
  bind_rows() %>%

9 Which tree parameters are tuned?

Parameter Mathematical role Bias-variance effect of increasing it
cp Minimum proportional loss reduction required for a split Increases bias and reduces variance
maxdepth Maximum number of decisions on a path Restricts interactions and reduces variance
minsplit Minimum parent-node sample size Prevents local splits supported by little data
minbucket Minimum terminal-node sample size Produces smoother, less extreme leaf probabilities

These values are hyperparameters: they are selected using resampling or validation games, not estimated by minimizing the final fitted tree’s training loss. Tutorial 2.7 develops a complete grouped tuning workflow.

12 Strengths and limitations

Single trees are easy to explain and automatically represent nonlinear relationships and interactions. They are also unstable: a small change in data can alter the first split and much of the remaining tree. Their piecewise-constant probabilities are often poorly calibrated. Ensembles address stability and predictive accuracy at the cost of simplicity.

14 Key takeaways

  • Classification trees minimize impurity; regression trees minimize squared error.
  • Trees discover thresholds and interactions automatically.
  • Unrestricted growth overfits, so pruning and node-size controls matter.
  • A single tree is an explanatory starting point, not usually the strongest probability model.
