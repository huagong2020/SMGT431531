1 Learning objectives

  • Translate the decision tree into matrices with named rows and columns.
  • Reproduce the backward-induction solution in base R.
  • Evaluate fixed policies and change the transition assumptions.

Open guided_lab.R or work through the code below. All inputs are hypothetical. The lab uses no packages or external data.

2 Step 1 (t=1→0t=1\to0). Value the final play

Start with the terminal vector 𝒗0\mathbf v_0 (terminal in R). At t=1t=1, P1 contains one matrix for each of the three states from Tutorial 7.4. The names lead, trail, and first_down correspond to sleads_{\mathrm{lead}}, strails_{\mathrm{trail}}, and s1sts_{\mathrm{1st}}. Each row describes one call. Its entries give the probabilities of a win and a loss for our team, even when the opponent has possession.

terminal <- c(win = 1, loss = 0)
P1 <- list(
  lead = rbind(opponent_attempt = c(win = 0.90, loss = 0.10)),
  trail = rbind(opponent_kneel = c(win = 0, loss = 1)),
  first_down = rbind(
    kick_52 = c(win = 0.65, loss = 0.35),
    end_zone_pass = c(win = 0.12, loss = 0.88)
  )
)

action_values <- function(transition, next_values) {
  stopifnot(
    all(colnames(transition) %in% names(next_values)),
    all(is.finite(transition)), all(transition >= 0),
    all(abs(rowSums(transition) - 1) < 1e-10)
  )
  drop(transition %*% next_values[colnames(transition)])
}

q1 <- lapply(P1, action_values, next_values = terminal)
v1 <- vapply(q1, max, numeric(1))
v1

The function aligns the value vector with the matrix columns before multiplying. At the states where the opponent has the ball, there is only one modeled call. At first down, max() selects the value of the 52-yard kick over the Hail Mary. The resulting v1 is 𝒗1\mathbf v_1.

3 Step 2 (t=2→1t=2\to1). Value the fourth-down actions

At s0s_0, P2 is the matrix 𝑷2\mathbf P_2. Its columns represent the three possible states at t=1t=1, and its rows represent the three fourth-down calls. Multiplying by 𝒗1\mathbf v_1 gives 𝒒2\mathbf q_2, stored in q2.

P2 <- rbind(
  kick_57 = c(lead = 0.40, trail = 0.60, first_down = 0),
  go      = c(lead = 0, trail = 0.45, first_down = 0.55),
  punt    = c(lead = 0, trail = 1, first_down = 0)
)

q2 <- action_values(P2, v1)
round(100 * q2, 2)
names(which.max(q2))
kick_57      go    punt
  36.00   35.75    0.00

4 Check by enumerating policies

There are three opening calls and two possible calls after a conversion. The six rows below pair each opening call with each continuation. To evaluate a row, insert the value of its specified continuation and use the transition row for its opening call.

policies <- expand.grid(
  first_action = rownames(P2),
  after_conversion = rownames(P1$first_down),
  stringsAsFactors = FALSE
)
policies$win_probability <- vapply(seq_len(nrow(policies)), function(i) {
  fixed_values <- v1
  fixed_values["first_down"] <- q1$first_down[policies$after_conversion[i]]
  fixed_action <- policies$first_action[i]
  action_values(P2[fixed_action, , drop = FALSE], fixed_values)[[1]]
}, numeric(1))

The best initial value agrees with backward induction. Two rows attain 0.3600 because the first-down state is never reached when the team opens with a kick. Backward induction still identifies the best action at that state.

5 Change the inputs

Raise the conversion probability to 56%. Reduce the failure probability by the same amount so the row remains a probability distribution.

P2_more_conversions <- P2
P2_more_conversions["go", c("trail", "first_down")] <- c(0.44, 0.56)
round(100 * action_values(P2_more_conversions, v1), 2)

5.1 Lab exercise

Return to the original conversion probability of 55%. Suppose the opponent now has a 15% chance of winning after our 57-yard field goal is made. Update the lead transition in P1 and rerun both stages. Which action is preferred, and by how many percentage points? Explain why the revised input affects one fourth-down action.

TipCheck your result

The lead state is worth 0.85. The long field goal is worth 0.40(0.85)=0.34000.40(0.85)=0.3400, while going is still worth 0.3575 and punting is worth zero. Going leads by 1.75 percentage points because only a made field goal reaches the lead state.
