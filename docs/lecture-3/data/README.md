# Soccer shot teaching data

`soccer_shots.rds` is generated by `R/prepare_soccer_shots.R` from
[StatsBomb Open Data](https://github.com/statsbomb/open-data). `model_results.rds`
is generated by `R/build_model_comparison.R` and holds the fitted predictions,
metrics, and diagnostics used by Tutorial 3.6.

## Provenance

| Field | Value |
|:--|:--|
| Provider | StatsBomb Open Data |
| Competition | FIFA World Cup, 2022 |
| Competition / season id | 43 / 106 |
| Matches | All 64 |
| Retrieved | 2026-08-23 (UTC) |

The full retrieval record is stored inside the file as `shots$provenance`.

## Contents

| Object | Shape | Meaning |
|:--|:--|:--|
| `spatial` | 1430 x 4 x 16 x 24 | Occupancy grid, channels-first (`N x C x H x W`) |
| `tabular` | 1430 x 10 | Shot features, unstandardized |
| `target` | 1430 | 1 when the shot was a goal |
| `metadata` | 1430 rows | Match, team, player, date, and split label |
| `feature_center`, `feature_scale` | 10 each | Training-set means and standard deviations |

The four spatial channels are `shooter`, `attacking_teammates`,
`outfield_defenders`, and `defending_goalkeeper`, measured on a 16 x 24 grid over
the 120 x 80 StatsBomb pitch.

## Exclusions and filtering

The preparation script removes penalty shots and any shot without an event
freeze frame. 1,430 shots remain, of which 152 (10.6%) are goals.

## Splits

Matches are ordered by date and assigned whole to one partition, so no match
contributes shots to more than one split.

| Split | Matches | Shots | Goals | Date range |
|:--|--:|--:|--:|:--|
| Training | 44 | 953 | 98 | 2022-11-20 to 2022-12-01 |
| Validation | 9 | 222 | 25 | 2022-12-02 to 2022-12-05 |
| Test | 11 | 255 | 29 | 2022-12-05 to 2022-12-18 |

Validation and test both contain matches played on 2022-12-05. They are
different matches, so no shot appears in two partitions, but the date boundary
is not strict. Treat the test set as "later matches" rather than "a strictly
later period."
