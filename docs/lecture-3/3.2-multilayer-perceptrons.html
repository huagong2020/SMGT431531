3.2 Multilayer Perceptrons

From logistic regression to a network that learns

Author

Hua Gong

1 Learning objectives

After this tutorial, you should be able to:

  • compute the output of one neuron and a small MLP;
  • explain why nonlinear activation functions matter;
  • derive the logistic cross-entropy gradient;
  • calculate backpropagation through hidden layers and take one gradient-descent step; and
  • define and train a small MLP with R torch.

2 From logistic regression to a neuron

Tutorial 3.1 used logistic regression to predict whether a shot becomes a goal. A neuron starts with the same calculation: multiply each input xjx_j by its weight wjw_j, add the products, then add a bias bb:

z=w1x1+⋯+wdxd+b=𝒘𝖳𝒙+b. z = w_1x_1+\cdots+w_dx_d+b=\mathbf{w}^{\mathsf T}\mathbf{x}+b.

The bold notation groups the dd inputs and weights into lists called vectors. An activation function transforms zz. Logistic regression uses sigmoid, σ(z)=1/(1+e−z)\sigma(z)=1/(1+e^{-z}), to turn this logit into a probability between 0 and 1.

2.1 Visual anatomy of one neuron

Training adjusts the weights and bias. The diagram’s constant input 1 contributes b×1=bb\times1=b.

A multilayer perceptron (MLP) adds intermediate groups of neurons called hidden layers. Their outputs become the next layer’s inputs. Our hidden neurons use ReLU, which keeps positive values and replaces negative values with zero:

ReLU⁡(z)=max⁡(0,z). \operatorname{ReLU}(z)=\max(0,z).

Without this nonlinear step, stacking layers would still produce just one weighted sum before sigmoid. ReLU lets the network learn more complex relationships.

NoteRead the two-hidden-layer notation

Each WW is a table of weights; 𝒃\mathbf{b} holds biases. The superscript identifies the layer, 𝒛\mathbf{z} holds weighted sums, and 𝒉\mathbf{h} holds activated outputs. Read from top to bottom:

𝒛(1)=W(1)𝒙+𝒃(1),𝒉(1)=ReLU⁡(𝒛(1)),𝒛(2)=W(2)𝒉(1)+𝒃(2),𝒉(2)=ReLU⁡(𝒛(2)),z(3)=W(3)𝒉(2)+b(3),p̂=σ(z(3)). \begin{aligned} \mathbf{z}^{(1)} &= W^{(1)}\mathbf{x}+\mathbf{b}^{(1)}, & \mathbf{h}^{(1)} &= \operatorname{ReLU}(\mathbf{z}^{(1)}),\\ \mathbf{z}^{(2)} &= W^{(2)}\mathbf{h}^{(1)}+\mathbf{b}^{(2)}, & \mathbf{h}^{(2)} &= \operatorname{ReLU}(\mathbf{z}^{(2)}),\\ z^{(3)} &= W^{(3)}\mathbf{h}^{(2)}+b^{(3)}, & \hat p &= \sigma(z^{(3)}). \end{aligned}

3 A numerical forward pass

A forward pass calculates a prediction from the current weights. Use two inputs, x1=0.5x_1=0.5 and x2=−1x_2=-1, and two hidden neurons. The inputs are standardized: zero represents a training-set mean, and negative values are below that mean.

Predict before running: find each weighted sum, called a pre-activation, then apply ReLU. These hand-chosen weights illustrate arithmetic, rather than fitted soccer effects. Each row of WW belongs to one hidden neuron.

x <- c(0.5, -1.0)
W <- matrix(
  c(0.8, -0.4,
    0.2,  0.6),
  nrow = 2,
  byrow = TRUE
)
b_hidden <- c(0.1, -0.2)

z_hidden <- as.numeric(W %*% x + b_hidden)
h <- pmax(0, z_hidden)

output_weights <- c(1.1, -0.7)
output_bias <- -0.2
logit <- sum(output_weights * h) + output_bias
probability <- 1 / (1 + exp(-logit))

data.frame(
  quantity = c("z1", "z2", "h1", "h2", "logit", "probability"),
  value = c(z_hidden, h, logit, probability)
) %>%
  knitr::kable(digits = 3)

4 Binary cross-entropy

A loss measures prediction error; smaller is better. Binary cross-entropy compares goal probability pp with outcome yy, where 1 means goal and 0 means no goal:

ℓ(y,p)=−[ylog(p)+(1−y)log(1−p)]. \ell(y,p)=-\left[y\log(p)+(1-y)\log(1-p)\right].

If y=1y=1, predicting p=0.9p=0.9 gives a small loss of −log⁡(0.9)=0.105-\log(0.9)=0.105. Predicting p=0.1p=0.1 gives a much larger loss of −log⁡(0.1)=2.303-\log(0.1)=2.303. Confident errors receive a strong penalty.

In R, nnf_binary_cross_entropy_with_logits() takes logits and observed outcomes, combining sigmoid and loss in one calculation. Give it matching shapes: one logit per outcome. Apply sigmoid separately to report probabilities.

WarningA common loss-function mistake

Do not apply sigmoid twice. For logit 2, sigmoid gives probability .881. Passing .881 into the logits-based loss applies sigmoid again, producing .707 internally and changing the calculation.

5 The key gradient

A gradient tells how loss changes with a small parameter change. Read ∂ℓ/∂w\partial\ell/\partial w as “the loss’s slope with respect to weight ww.” Gradient descent subtracts a small multiple of that slope to reduce loss.

Backpropagation finds these slopes backward from the loss. The chain rule multiplies slopes along a sequence of calculations; when paths meet, add their contributions. The three examples use one observation and no extra penalty on weights. Keep unrounded values while calculating.

5.1 Example 1: Trace the loss backward through one neuron

Use x1=0.5x_1=0.5, x2=−1x_2=-1, w1=0.8w_1=0.8, w2=−0.4w_2=-0.4, b=0.1b=0.1, and target y=1y=1. This first example has no hidden layer.

Forward pass.

z=0.8(0.5)+(−0.4)(−1)+0.1=0.9,p=σ(0.9)≈0.710950,ℓ=−log⁡(p)≈0.341154. \begin{aligned} z&=0.8(0.5)+(-0.4)(-1)+0.1=0.9,\\ p&=\sigma(0.9)\approx0.710950,\\ \ell&=-\log(p)\approx0.341154. \end{aligned}

Backward pass: loss to probability, then probability to logit. Because y=1y=1, the loss is −log⁡(p)-\log(p):

∂ℓ∂p=−1p≈−1.406570,∂p∂z=p(1−p)≈0.205500,∂ℓ∂z=∂ℓ∂p∂p∂z≈(−1.406570)(0.205500)=−0.289050. \begin{aligned} \frac{\partial\ell}{\partial p}&=-\frac{1}{p}\approx-1.406570,\\ \frac{\partial p}{\partial z}&=p(1-p)\approx0.205500,\\ \frac{\partial\ell}{\partial z} &=\frac{\partial\ell}{\partial p}\frac{\partial p}{\partial z}\\ &\approx(-1.406570)(0.205500)=-0.289050. \end{aligned}

Multiplying the two slopes gives p−yp-y. The same shortcut works for y=0y=0 or y=1y=1:

∂ℓ∂z=(−yp+1−y1−p)p(1−p)=−y(1−p)+(1−y)p=p−y. \begin{aligned} \frac{\partial\ell}{\partial z} &=\left(-\frac{y}{p}+\frac{1-y}{1-p}\right)p(1-p)\\ &=-y(1-p)+(1-y)p=p-y. \end{aligned}

Continue backward from the logit to each parameter. Since z=w1x1+w2x2+bz=w_1x_1+w_2x_2+b, the local derivatives are x1x_1, x2x_2, and 11:

∂ℓ∂w1=(−0.289050)(0.5)=−0.144525,∂ℓ∂w2=(−0.289050)(−1)=0.289050,∂ℓ∂b=(−0.289050)(1)=−0.289050. \begin{aligned} \frac{\partial\ell}{\partial w_1}&=(-0.289050)(0.5)=-0.144525,\\ \frac{\partial\ell}{\partial w_2}&=(-0.289050)(-1)=0.289050,\\ \frac{\partial\ell}{\partial b}&=(-0.289050)(1)=-0.289050. \end{aligned}

Thus ∂ℓ/∂𝒘=(p−y)𝒙\partial\ell/\partial\mathbf{w}=(p-y)\mathbf{x}. Notice the opposite signs of the two weight gradients: gradient descent increases w1w_1 and decreases w2w_2. Both changes raise the logit for this observation because x2x_2 is negative.

5.2 Example 2: Backpropagate through the two-unit hidden layer

Return to Section 3’s network with y=1y=1. Output weights are v1,v2v_1,v_2 and bias is cc. In WW, rows identify hidden units and columns identify inputs:

W=[0.8−0.40.20.6],𝒃=[0.1−0.2],𝒗=[1.1−0.7],c=−0.2. W=\begin{bmatrix}0.8&-0.4\\0.2&0.6\end{bmatrix}, \qquad \mathbf{b}=\begin{bmatrix}0.1\\-0.2\end{bmatrix}, \qquad \mathbf{v}=\begin{bmatrix}1.1\\-0.7\end{bmatrix}, \qquad c=-0.2.

Step 1: Save the forward-pass values. For 𝒙=(0.5,−1)\mathbf{x}=(0.5,-1),

a1=0.8(0.5)+(−0.4)(−1)+0.1=0.9,h1=ReLU⁡(a1)=0.9,a2=0.2(0.5)+0.6(−1)−0.2=−0.7,h2=ReLU⁡(a2)=0,z=1.1(0.9)+(−0.7)(0)−0.2=0.79. \begin{aligned} a_1&=0.8(0.5)+(-0.4)(-1)+0.1=0.9, & h_1&=\operatorname{ReLU}(a_1)=0.9,\\ a_2&=0.2(0.5)+0.6(-1)-0.2=-0.7, & h_2&=\operatorname{ReLU}(a_2)=0,\\ z&=1.1(0.9)+(-0.7)(0)-0.2=0.79. \end{aligned}

Here a1,a2a_1,a_2 correspond to z_hidden in the code. Probability is p≈0.687831p\approx0.687831 and loss is ℓ≈0.374212\ell\approx0.374212.

Step 2: Work backward through the output layer. Use δout\delta_{\mathrm{out}} (delta) as shorthand for the loss slope at the output logit:

δout=∂ℓ∂z=p−y=0.687831−1=−0.312169. \delta_{\mathrm{out}}=\frac{\partial\ell}{\partial z} =p-y=0.687831-1=-0.312169.

The local derivative of z=v1h1+v2h2+cz=v_1h_1+v_2h_2+c with respect to each output weight is its hidden input:

∂ℓ∂v1=δouth1≈(−0.312169)(0.9)=−0.280952,∂ℓ∂v2=δouth2=(−0.312169)(0)=0,∂ℓ∂c=δout≈−0.312169. \begin{aligned} \frac{\partial\ell}{\partial v_1}&=\delta_{\mathrm{out}}h_1\approx(-0.312169)(0.9)=-0.280952,\\ \frac{\partial\ell}{\partial v_2}&=\delta_{\mathrm{out}}h_2=(-0.312169)(0)=0,\\ \frac{\partial\ell}{\partial c}&=\delta_{\mathrm{out}}\approx-0.312169. \end{aligned}

Step 3: Pass the derivative through each ReLU. A positive input passes through unchanged, so its slope is 1. A negative input produces constant zero, so its slope is 0. R torch also uses slope 0 at the corner, zero.

Multiply three factors: the loss derivative at the output logit, the connecting output weight, and the hidden unit’s activation derivative.

δ1=∂ℓ∂a1=δoutv1ReLU⁡′(a1)≈(−0.312169)(1.1)(1)=−0.343386,δ2=∂ℓ∂a2=δoutv2ReLU⁡′(a2)≈(−0.312169)(−0.7)(0)=0. \begin{aligned} \delta_1=\frac{\partial\ell}{\partial a_1} &=\delta_{\mathrm{out}}v_1\operatorname{ReLU}'(a_1)\\ &\approx(-0.312169)(1.1)(1)=-0.343386,\\ \delta_2=\frac{\partial\ell}{\partial a_2} &=\delta_{\mathrm{out}}v_2\operatorname{ReLU}'(a_2)\\ &\approx(-0.312169)(-0.7)(0)=0. \end{aligned}

The slope at h2h_2 is ∂ℓ/∂h2≈0.218518\partial\ell/\partial h_2\approx0.218518, but ReLU blocks it from reaching a2a_2. Another observation may activate this unit.

Step 4: Continue to the hidden weights and biases. Each aj=Wj1x1+Wj2x2+bja_j=W_{j1}x_1+W_{j2}x_2+b_j, so multiply δj\delta_j by the corresponding input (or by 1 for the bias):

The goal probability rose from 0.6878310.687831 to 0.7178170.717817 and loss fell from 0.3742120.374212 to 0.3315400.331540. This step helped; a much larger learning rate might not. The fitted model uses Adam, an update method explained in Tutorial 3.3.

5.3 Example 3: Add contributions from two backward paths

One hidden unit can feed several later units. Its gradient must include every path to the loss. Consider this separate network with x=1x=1 and y=1y=1:

a=wx+b=0.5(1)+0=0.5,h=ReLU⁡(a)=0.5,aA=2h+0.1=1.1,gA=ReLU⁡(aA)=1.1,aB=−h+1=0.5,gB=ReLU⁡(aB)=0.5,z=0.6gA−0.4gB−0.2=0.26,p=σ(0.26)≈0.564636. \begin{aligned} a&=wx+b=0.5(1)+0=0.5, & h&=\operatorname{ReLU}(a)=0.5,\\ a_A&=2h+0.1=1.1, & g_A&=\operatorname{ReLU}(a_A)=1.1,\\ a_B&=-h+1=0.5, & g_B&=\operatorname{ReLU}(a_B)=0.5,\\ z&=0.6g_A-0.4g_B-0.2=0.26, & p&=\sigma(0.26)\approx0.564636. \end{aligned}

All three ReLUs are active, so their local derivatives are 1. Start with δout=p−y≈−0.435364\delta_{\mathrm{out}}=p-y\approx-0.435364. Now follow the two routes from the loss back to hh:

Via gA:∂ℓ∂z∂z∂gA∂gA∂aA∂aA∂h≈(−0.435364)(0.6)(1)(2)≈−0.522436,Via gB:∂ℓ∂z∂z∂gB∂gB∂aB∂aB∂h≈(−0.435364)(−0.4)(1)(−1)≈−0.174145. \begin{aligned} \text{Via }g_A:\quad \frac{\partial\ell}{\partial z} \frac{\partial z}{\partial g_A} \frac{\partial g_A}{\partial a_A} \frac{\partial a_A}{\partial h} &\approx(-0.435364)(0.6)(1)(2)\\ &\approx-0.522436,\\ \text{Via }g_B:\quad \frac{\partial\ell}{\partial z} \frac{\partial z}{\partial g_B} \frac{\partial g_B}{\partial a_B} \frac{\partial a_B}{\partial h} &\approx(-0.435364)(-0.4)(1)(-1)\\ &\approx-0.174145. \end{aligned}

Add the paths before continuing to the earlier weight:

∂ℓ∂h≈−0.522436−0.174145≈−0.696582,∂ℓ∂w=∂ℓ∂hReLU⁡′(a)x≈(−0.696582)(1)(1)=−0.696582,∂ℓ∂b=∂ℓ∂hReLU⁡′(a)≈−0.696582. \begin{aligned} \frac{\partial\ell}{\partial h} &\approx-0.522436-0.174145\approx-0.696582,\\ \frac{\partial\ell}{\partial w} &=\frac{\partial\ell}{\partial h}\operatorname{ReLU}'(a)x \approx(-0.696582)(1)(1)=-0.696582,\\ \frac{\partial\ell}{\partial b} &=\frac{\partial\ell}{\partial h}\operatorname{ReLU}'(a) \approx-0.696582. \end{aligned}

Using only gAg_A would miss part of ww’s effect. Backpropagation adds both contributions automatically.

TipThe hand-calculation routine
  1. Run the forward pass and save each pre-activation and activation.
  2. Start at the output loss with δout=p−y\delta_{\mathrm{out}}=p-y.
  3. Move backward, multiplying by local derivatives and adding contributions wherever paths meet.
  4. Calculate each parameter gradient, then let the optimizer update the parameters.

For a mini-batch, a small group of observations, average their loss gradients before updating. The examples above each use one observation.

7 Define the shot MLP

Return to the soccer data from Tutorial 3.1. Our network takes 10 features, passes them through hidden layers of 12 and 6 neurons, and returns one logit:

10→12→6→1. 10 \rightarrow 12 \rightarrow 6 \rightarrow 1.

For BB shots, B×12B\times12 means 12 values per shot. The shapes follow B×10→B×12→B×6→B×1B\times10\rightarrow B\times12\rightarrow B\times6\rightarrow B\times1. A dense layer connects every input to every output, with one bias per output. Count 217 parameters:

(10⋅12+12)+(12⋅6+6)+(6⋅1+1)=217. (10\cdot12+12)+(12\cdot6+6)+(6\cdot1+1)=217.

nn_module() defines a model constructor. initialize() creates its layers once; forward() describes what happens each time we call model(x). self refers to this model and stores its layers. Their weights automatically become trainable parameters.

NoteDefine and inspect the model in R

nn_linear(10, 12) makes 12 neurons reading 10 inputs; nn_relu() applies ReLU; nn_sequential() runs the layers in order.

mlp_module <- nn_module(
  # Build and store layers when a new model is created.
  initialize = function(number_of_features = 10L) {
    self$network <- nn_sequential(
      nn_linear(number_of_features, 12), nn_relu(),
      nn_linear(12, 6), nn_relu(),
      nn_linear(6, 1) # One logit; the loss handles sigmoid
    )
  },
  forward = function(x) self$network(x) # Run the stored layers in order
)
mlp <- mlp_module(number_of_features = 10)

8 Train the network

fit_binary_model() is our course helper in torch_helpers.R, not a built-in torch function. It repeats prediction, loss calculation, backpropagation, and updates. Each mini-batch has up to 64 shots; an epoch visits all training shots. patience = 5 stops after five epochs without a qualifying validation improvement. Tutorial 3.3 explains these settings.

torch_manual_seed(431)

mlp_fit <- fit_binary_model(
  model = mlp_module(number_of_features = 10),
  x = tensors$tabular, # N x 10 standardized inputs
  y = tensors$target,  # N x 1 observed outcomes
  training_indices = tensors$train,
  validation_indices = tensors$validation,
  epochs = 30,
  batch_size = 64,
  learning_rate = 0.01,
  patience = 5,
  seed = 431
)

data.frame(
  best_epoch = mlp_fit$best_epoch,

mlp_fit is a list: $model holds the best saved network, $history holds epoch losses, and $best_epoch identifies the chosen checkpoint.

Lower loss is better. Training loss averages batches while weights change; validation loss is measured afterward with fixed weights. Their gap helps diagnose learning, but the curves use different conditions. Early stopping restores the best saved validation weights.

9 Check validation probabilities

Validation shots help choose settings; they do not update weights. The helper converts logits into probabilities and compares them with observed outcomes:

11 Key takeaways

  • Hidden neurons learn new combinations of the original inputs.
  • ReLU adds nonlinear relationships; binary cross-entropy measures prediction error.
  • Backpropagation computes gradients; the optimizer uses them to update parameters.
  • Validation guides model choices; separate test data checks predictions on new matches.
