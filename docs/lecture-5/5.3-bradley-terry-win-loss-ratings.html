5.3 Win-Loss Ratings: Bradley-Terry and Logistic Models

Author

Hua Gong

1 Learning objectives

After this tutorial, you should be able to:

  • write the Bradley-Terry model and show that it is a logistic regression on the ±1\pm1 design matrix;
  • fit it with and without a home-advantage term and interpret ratings on the log-odds scale;
  • recognize the separation problem and fix it with a prior;
  • show that the Elo expected score is a Bradley-Terry probability and that the Elo update is a gradient step on its log-likelihood;
  • extend the model to ordered outcomes for sports with draws; and
  • compare win-loss ratings with margin-based ratings on held-out games.

2 The Bradley-Terry model

Assign each team a positive strength πj\pi_j and let

P(i beats j)=πiπi+πj. P(i\text{ beats }j)=\frac{\pi_i}{\pi_i+\pi_j}.

Writing θj=log⁡πj\theta_j=\log\pi_j gives

P(i beats j)=eθieθi+eθj=σ(θi−θj), P(i\text{ beats }j)=\frac{e^{\theta_i}}{e^{\theta_i}+e^{\theta_j}}=\sigma(\theta_i-\theta_j),

where σ\sigma is the logistic function. The probability depends only on the difference in ratings, so a constant can be added to every θj\theta_j without changing anything: the same identification issue as in Tutorial 5.2, resolved the same way.

With a home advantage α\alpha and the design matrix XX of Tutorial 5.2,

P(home wins game g)=σ(αhg+∑jxgjθj), P(\text{home wins game }g)=\sigma\!\left(\alpha h_g+\sum_j x_{gj}\theta_j\right),

which is a logistic regression with no intercept, one column for home field, and the ±1\pm1 team columns. Everything we know about logistic regression applies: the log-likelihood

ℓ(α,𝜽)=∑g[yglogpg+(1−yg)log(1−pg)] \ell(\alpha,\boldsymbol\theta)=\sum_g\left[y_g\log p_g+(1-y_g)\log(1-p_g)\right]

is concave, maximum likelihood is a standard glm() call, and the coefficients are log-odds.

The two agree strongly but not perfectly. Teams above the line won more games than their margins predict. The slope relates the two scales: because Φ(z)≈σ(1.7z)\Phi(z)\approx\sigma(1.7z), a one-point margin rating is worth roughly 1.7/σ≈0.131.7/\sigma\approx0.13 log-odds when the margin noise is σ≈13\sigma\approx13 points.

NoteWhich is better?

The margin model uses more information and its ratings are less noisy, which is why professional rating systems use margins whenever they are available. The Bradley-Terry model is the right tool when only wins and losses are recorded or when margins are unreliable, as in sports with running up the score or garbage time.

3 The separation problem

Early in a season, some team has won every game. Maximum likelihood then tries to send that team’s rating to +∞+\infty, because no finite value makes the probability of its record equal to one. The same happens whenever the teams can be split into two groups where every game between the groups was won by the same side.

early <- games_2023 %>% filter(week <= 5, tie == 0)
X_early <- build_design_matrix(early)
design_early <- data.frame(home_win = early$home_win, home = 1 - early$neutral_site, X_early[, -1])

early_fit <- suppressWarnings(glm(home_win ~ 0 + ., data = design_early, family = binomial()))

early_ratings <- c(0, coef(early_fit)[-1])
names(early_ratings) <- colnames(X_early)

data.frame(team = names(early_ratings), rating = early_ratings - mean(early_ratings)) %>%
  arrange(desc(rating)) %>%
  slice(c(1:4, 29:32)) %>%

Ratings in the tens of log-odds are meaningless: they say an undefeated team would beat an average team with probability indistinguishable from one after five games. A prior fixes this in exactly the way it fixed the plus-minus problem in Lecture 4.

3.1 A Bayesian Bradley-Terry model

Put θj∼N(0,τ2)\theta_j\sim N(0,\tau^2) on every rating. The posterior mode is a penalized logistic regression; the full posterior is available from rstanarm. A prior standard deviation of 1 log-odds says that before the season, a typical team beats an average team somewhere between 27% and 73% of the time, which is a reasonable statement about the NFL.

library(rstanarm)

design_early_all <- data.frame(home_win = early$home_win, home = 1 - early$neutral_site, X_early)

bayes_early <- stan_glm(
  home_win ~ 0 + .,
  data = design_early_all,
  family = binomial(),
  prior = normal(0, c(1, rep(1, ncol(X_early)))),
  chains = 4,
  iter = 2000,
  seed = 431,
  refresh = 0
)
early_draws <- as.matrix(bayes_early)[, colnames(X_early)]
early_draws <- early_draws - rowMeans(early_draws)

data.frame(
  team = colnames(early_draws),
  posterior_mean = colMeans(early_draws),
  posterior_sd = apply(early_draws, 2, sd)
) %>%
  arrange(desc(posterior_mean)) %>%
  slice(c(1:4, 29:32)) %>%
  knitr::kable(digits = 2, row.names = FALSE)

4 Elo is an online Bradley-Terry model

The Elo system computes the expected score of team ii against team jj as

Ei=11+10−(Ri−Rj)/400, E_i=\frac{1}{1+10^{-(R_i-R_j)/400}},

and after the game updates Ri←Ri+K(Si−Ei)R_i\leftarrow R_i+K(S_i-E_i), where SiS_i is 1 for a win, 0 for a loss, and 0.5 for a tie.

Two facts connect this to the model above.

The expected score is a Bradley-Terry probability. Since 10−x/400=e−xln⁡10/40010^{-x/400}=e^{-x\ln10/400},

Ei=σ(ln⁡10400(Ri−Rj)), E_i=\sigma\!\left(\frac{\ln 10}{400}(R_i-R_j)\right),

so θj=Rjln⁡10/400\theta_j=R_j\ln10/400. An Elo gap of 400 points is a rating difference of about 2.3 log-odds, or a 91% win probability.

The update is a gradient step. The derivative of one game’s log-likelihood with respect to θi\theta_i is

∂∂θi[ylogp+(1−y)log(1−p)]=y−p, \frac{\partial}{\partial\theta_i}\left[y\log p+(1-y)\log(1-p)\right]=y-p,

where p=σ(θi−θj)p=\sigma(\theta_i-\theta_j). The Elo update adds K(Si−Ei)K(S_i-E_i), which is a step of size KK along that gradient. Elo is therefore stochastic gradient ascent on the Bradley-Terry log-likelihood, processing one game at a time and never revisiting old games. The constant KK controls how fast ratings respond, and Tutorial 5.5 shows that it plays the same role as the innovation variance of a state-space model.

5 Ordered outcomes: soccer

A soccer match has three outcomes. Order them as away win ≺\prec draw ≺\prec home win and let zg=α+θhome−θawayz_g=\alpha+\theta_{\text{home}}-\theta_{\text{away}}. The cumulative logit (proportional odds) model places two thresholds on the latent scale:

P(away win)=σ(c1−zg),P(away win or draw)=σ(c2−zg), P(\text{away win})=\sigma(c_1-z_g), \qquad P(\text{away win or draw})=\sigma(c_2-z_g),

with c1<c2c_1<c_2, so that P(draw)=σ(c2−zg)−σ(c1−zg)P(\text{draw})=\sigma(c_2-z_g)-\sigma(c_1-z_g) and P(home win)=1−σ(c2−zg)P(\text{home win})=1-\sigma(c_2-z_g). The gap c2−c1c_2-c_1 controls how often draws occur. When c1=c2c_1=c_2 the model collapses to Bradley-Terry.

6 Held-out comparison

Fit the Bradley-Terry and margin models on weeks 1 through 14 of 2023 and score their home-win probabilities on weeks 15 through 18. To avoid the separation problem in the training window, the Bradley-Terry fit uses a mild ridge penalty implemented as the posterior mode with τ=1\tau=1.

train <- games_2023 %>% filter(week <= 14, tie == 0)
test <- games_2023 %>% filter(week >= 15, tie == 0)
X_train <- build_design_matrix(train, teams = colnames(X))
X_test <- build_design_matrix(test, teams = colnames(X))

# Penalized logistic regression by Newton's method: the posterior mode with
# a N(0, tau^2) prior on every team rating and a N(0, 3^2) prior on home field.
penalized_logistic <- function(A, y, prior_sd) {
  beta <- rep(0, ncol(A))
  penalty <- diag(1 / prior_sd^2)
  for (iteration in seq_len(50)) {
    p <- plogis(as.numeric(A %*% beta))
    gradient <- as.numeric(t(A) %*% (y - p)) - penalty %*% beta
    hessian <- t(A) %*% (A * (p * (1 - p))) + penalty
    step <- solve(hessian, gradient)
    beta <- beta + as.numeric(step)
    if (max(abs(step)) < 1e-8) break
  }
  beta
}

A_train <- cbind(home = 1 - train$neutral_site, X_train)
bt_beta <- penalized_logistic(A_train, train$home_win, prior_sd = c(3, rep(1, ncol(X_train))))
bt_probability <- plogis(as.numeric(cbind(1 - test$neutral_site, X_test) %*% bt_beta))

margin_train <- ridge_ratings(train, lambda = 7)
margin_prediction <- margin_train$home_advantage * (1 - test$neutral_site) +
  margin_train$ratings[test$home_team] - margin_train$ratings[test$away_team]
margin_probability <- pnorm(margin_prediction / 13)

data.frame(
  model = c("Bradley-Terry (penalized)", "ridge on margins"),
  log_loss = c(log_loss(test$home_win, bt_probability), log_loss(test$home_win, margin_probability)),
  brier = c(brier_score(test$home_win, bt_probability), brier_score(test$home_win, margin_probability))
) %>%
  knitr::kable(digits = 3)
model log_loss brier
Bradley-Terry (penalized) 0.655 0.230
ridge on margins 0.635 0.223

The margin model usually scores better because it has seen more information per game, but in a single late-season window of about 60 games the gap is within noise. Tutorial 5.6 evaluates both across full seasons.

8 Key takeaways

  • Bradley-Terry is logistic regression on the ±1\pm1 design; ratings are log-odds.
  • Undefeated teams break maximum likelihood; a normal prior restores finite, interpretable ratings.
  • Elo’s expected score is a Bradley-Terry probability and its update is a gradient step with step size KK.
  • Ordered-outcome models handle draws with thresholds on the latent scale.
  • Margin models extract more information per game; win-loss models are for when margins are unavailable or untrustworthy.
