5.6 Evaluating and Communicating Team Ratings

Author

Hua Gong

1 Learning objectives

After this tutorial, you should be able to:

  • evaluate sequential forecasts without look-ahead and explain why a warm-up period is needed;
  • convert moneylines and spreads into probabilities and remove the bookmaker’s margin;
  • compare rating systems with the market on log loss, Brier score, and calibration;
  • explain break-even probabilities, expected value, and why beating the market is hard;
  • turn a posterior over ratings into probabilities for rankings; and
  • write a rating report that states its scale, uncertainty, and limitations.

2 The rule for scoring sequential forecasts

A forecast may use only information available before kickoff, including information used to set tuning parameters. Sequential updates alone do not prevent leakage if hyperparameters were fitted using future games. Here we fix illustrative hyperparameters in advance rather than use the stored full-period Stan fit for forecast scoring. The 2022 season supplies initial ratings and the baseline home-win rate. We score 2023 and 2024 games with decisive outcomes. This targets performance among decisive games. A full outcome model would include ties explicitly.

baseline_home_rate <- with(subset(nfl, season == 2022 & tie == 0), mean(home_win))

elo <- run_elo(nfl, k = 20, home_advantage = 55, margin_multiplier = TRUE)
kalman <- kalman_ratings(
  nfl,
  sigma_obs = 13, sigma_week = 1.2,
  sigma_season = 4, rho = 0.6,
  home_advantage = 2, initial_sd = 6
)

# Rolling ridge: before each week, refit on the current season's earlier games.
rolling_ridge <- nfl %>%
  mutate(ridge_margin = NA_real_)
for (s in unique(nfl$season)) {
  for (w in sort(unique(nfl$week[nfl$season == s]))) {
    rows <- which(nfl$season == s & nfl$week == w)
    history <- nfl %>% filter(season == s, week < w)
    if (nrow(history) < 16) {
      rolling_ridge$ridge_margin[rows] <- 2 * (1 - nfl$neutral_site[rows])
    } else {
      fit <- ridge_ratings(history, lambda = 7)
      rolling_ridge$ridge_margin[rows] <- fit$home_advantage * (1 - nfl$neutral_site[rows]) +
        fit$ratings[nfl$home_team[rows]] - fit$ratings[nfl$away_team[rows]]
    }
  }
}

forecasts <- nfl %>%
  select(game_id, season, week, home_team, away_team, margin, home_win, tie, spread_line, home_moneyline, away_moneyline) %>%
  left_join(elo$games %>% select(game_id, elo_prob = home_prob), by = "game_id") %>%
  left_join(kalman$predictions %>% select(game_id, kalman_margin = predicted_margin, kalman_prob = home_prob), by = "game_id") %>%
  left_join(rolling_ridge %>% select(game_id, ridge_margin), by = "game_id") %>%
  mutate(
    ridge_prob = pnorm(ridge_margin / 13),
    market_prob = remove_vig(moneyline_to_probability(home_moneyline), moneyline_to_probability(away_moneyline))[, 1],
    spread_prob = pnorm(spread_line / 13.5)
  ) %>%
  filter(season >= 2023, tie == 0, !is.na(market_prob))

3 The market as a benchmark

A moneyline of −150-150 means a bettor risks 150 to win 100; a moneyline of +130+130 means risking 100 wins 130. The implied probabilities are

pimplied={|M||M|+100,M<0,100M+100,M>0. p_{\text{implied}}= \begin{cases} \dfrac{|M|}{|M|+100}, & M<0,\\[10pt] \dfrac{100}{M+100}, & M>0. \end{cases}

The two sides of a game imply probabilities that sum to more than one. The excess is the bookmaker’s margin, called the vig or hold, and dividing each implied probability by the sum removes it.

example <- nfl %>% filter(season == 2023, week == 1) %>% slice_head(n = 4)
example %>%
  transmute(
    home_team, away_team, home_moneyline, away_moneyline,
    implied_home = moneyline_to_probability(home_moneyline),
    implied_away = moneyline_to_probability(away_moneyline),
    hold = implied_home + implied_away - 1,
    fair_home = remove_vig(implied_home, implied_away)[, 1]
  ) %>%
  knitr::kable(digits = 3)

4 Comparing the systems

score <- function(probability, label) {
  data.frame(
    model = label,
    log_loss = log_loss(forecasts$home_win, probability),
    brier = brier_score(forecasts$home_win, probability),
    accuracy = mean((probability > 0.5) == forecasts$home_win)
  )
}

4.1 Calibration

calibration <- bind_rows(
  forecasts %>% transmute(model = "Elo", probability = elo_prob, home_win),
  forecasts %>% transmute(model = "Kalman filter", probability = kalman_prob, home_win),
  forecasts %>% transmute(model = "market (moneyline)", probability = market_prob, home_win)
) %>%
  mutate(bin = cut(probability, breaks = seq(0, 1, by = 0.1), include.lowest = TRUE)) %>%
  group_by(model, bin) %>%
  summarize(mean_forecast = mean(probability), observed = mean(home_win), games = n(), .groups = "drop") %>%
  filter(games >= 10)

ggplot(calibration, aes(mean_forecast, observed, color = model)) +
  geom_abline(slope = 1, intercept = 0, linetype = "dashed", color = "gray50") +
  geom_point(aes(size = games)) +
  geom_line() +
  coord_equal(xlim = c(0, 1), ylim = c(0, 1)) +

With roughly 540 games, many bins contain only a few dozen outcomes. Differences from the diagonal may reflect sampling variability as well as miscalibration. Inspect bin sizes and uncertainty rather than concluding that a visually close curve proves calibration.

5 Break-even, expected value, and the difficulty of beating the market

A bet at decimal odds oo (American +M+M converts to o=1+M/100o=1+M/100; −M-M converts to o=1+100/Mo=1+100/M) returns oo per unit staked if it wins. If the true probability is pp, the expected profit per unit is

EV=po−1, \text{EV}=p\,o-1,

and the bet breaks even at p*=1/op^{*}=1/o, which is exactly the implied probability before the vig is removed. To profit, a model’s probability must exceed the implied probability of the bettor’s side, which already includes the hold, and it must do so reliably.

edges <- forecasts %>%
  mutate(
    odds_home = ifelse(home_moneyline > 0, 1 + home_moneyline / 100, 1 + 100 / abs(home_moneyline)),
    odds_away = ifelse(away_moneyline > 0, 1 + away_moneyline / 100, 1 + 100 / abs(away_moneyline)),
    ev_home = kalman_prob * odds_home - 1,
    ev_away = (1 - kalman_prob) * odds_away - 1,
    bet = case_when(ev_home > 0.05 ~ "home", ev_away > 0.05 ~ "away", TRUE ~ "none"),
    profit = case_when(
      bet == "home" ~ ifelse(home_win == 1, odds_home - 1, -1),
      bet == "away" ~ ifelse(home_win == 0, odds_away - 1, -1),
      TRUE ~ 0
    )
  )

edges %>%
  filter(bet != "none") %>%
  summarize(
    bets = n(),
    win_rate = mean(profit > 0),
    total_profit_per_unit_staked = sum(profit) / n(),
    mean_model_edge = mean(pmax(ev_home, ev_away))
  ) %>%
  knitr::kable(digits = 3)
bets win_rate total_profit_per_unit_staked mean_model_edge
338 0.343 -0.11 0.272

The fixed-rule illustration has a negative realized return in this historical sample. This does not isolate the source of every forecast error or establish what would happen in another period. A model-implied edge requires independent evaluation, uncertainty analysis, and a realistic treatment of available odds before it supports a decision.

WarningTwo cautions

First, an apparent edge on one season of games is within noise; a return of a few percent on a few hundred bets has a standard error of several percent. Second, the Kelly criterion f*=(po−1)/(o−1)f^{*}=(po-1)/(o-1) gives the stake fraction that maximizes long-run growth if pp is correct; with an overconfident model it produces ruin faster than flat betting.

6 Rankings with uncertainty

The Stan posterior for the final period turns every question about the ranking into a probability.

draws <- state_space$final_theta_draws
ranks <- t(apply(-draws, 1, rank, ties.method = "first"))
colnames(ranks) <- colnames(draws)

ranking <- data.frame(
  team = colnames(draws),
  posterior_mean = colMeans(draws),
  posterior_sd = apply(draws, 2, sd),
  probability_best = colMeans(ranks == 1),
  probability_top_5 = colMeans(ranks <= 5),

Even the strongest team at season’s end has a meaningful chance of being only the third- or fourth-best team. A published ranking that omits this is stating a posterior mode as if it were a fact.

7 Communicating a rating

A rating report should let a reader answer four questions without contacting the analyst.

  1. What is the scale? Points against an average opponent on a neutral field, log-odds, or Elo points. State it, and give the home advantage on the same scale.
  2. How uncertain is each rating? Report an interval, or at least a standard deviation, and say what it excludes.
  3. When is the rating for? A season-long average, a smoothed estimate for a date, or a forecast for the next game are different objects.
  4. What does the model not see? Injuries, suspensions, weather, and motivation are absent from results-only models. Say so, and compare with the market where possible.

A reporting checklist for team ratings:

  • outcome modeled (result, margin, or goals) and data window;
  • design of the model, including home advantage, neutral sites, and ties;
  • prior or penalty and the estimated variance components;
  • for dynamic models, the drift and between-season assumptions;
  • forecast evaluation on games not used for fitting, against a market benchmark;
  • rankings as probabilities; and
  • known limitations.

9 Key takeaways

  • Score forecasts made only with pregame information, after a warm-up period, and exclude outcomes the forecast cannot express.
  • Moneylines convert to probabilities; remove the hold before comparing with a model.
  • The market beats results-only models; the state-space model is the best of those models and the rolling static model the worst.
  • Apparent betting edges from a results-only model do not survive the hold; treat market log loss as the bar to clear.
  • Report rankings as rank probabilities and state scale, uncertainty, timing, and blind spots.
