Lecture 6: Clustering Methods for Sport

Author

Hua Gong

1 The question for this lecture

What kinds of players are there, and which players are alike?

Positions are labels handed down by tradition. A modern NBA roster contains centers who shoot threes, forwards who run the offense, and guards who never handle the ball. Clustering asks the data instead of the label: given a set of measurements for each player, which players belong together, how many groups are there, and how confident should we be in the answer?

This lecture treats clustering as a modeling decision rather than a button to press. It builds up from the classical algorithms to the choices that actually determine the result:

  1. Representation and distance. What to measure, how to transform and weight it, and what “far apart” means.
  2. k-means and k-medoids. The workhorse algorithms, implemented from scratch and then with packages, with rules for choosing the number of clusters.
  3. Hierarchical clustering. Trees of players, linkage rules, and the difference between archetypes and comparables.
  4. Gaussian mixture models. Clustering as a probability model fitted by the EM algorithm, with soft memberships, model selection by BIC, and a Bayesian view.
  5. Density-based, graph-based, and factorization methods. DBSCAN and HDBSCAN, spectral clustering, and non-negative matrix factorization for shot charts.
  6. Validation. Internal indexes, bootstrap stability, agreement with external labels, and honest communication.

3 Data

The file data/nba_2024.rds holds two objects built from ESPN box scores and play-by-play for the 2023-24 NBA regular season through hoopR.

library(dplyr)
source("R/cluster_helpers.R")

nba <- load_nba()

data.frame(
  object = c("profiles", "shots"),
  rows = c(nrow(nba$profiles), nrow(nba$shots)),
  description = c(
    "player-season totals and per-36 rates for players with at least 500 minutes",
    "field-goal attempts with half-court coordinates"
  )
) %>%
  knitr::kable()
object rows description
profiles 360 player-season totals and per-36 rates for players with at least 500 minutes
shots 219105 field-goal attempts with half-court coordinates

The profiles carry each player’s listed position, which the tutorials use only as an external reference for validation, never as an input to the clustering. data/README.md records the provenance and filters.

NoteScope of the examples

Box-score rates describe what a player did, not what they were asked to do. A cluster of “low-usage spot-up shooters” mixes players with that skill set and players whose teams gave them that role. Every clustering in this lecture is a description of the season’s data, not a measurement of ability.
