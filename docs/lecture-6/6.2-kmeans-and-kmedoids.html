6.2 k-Means and k-Medoids

Author

Hua Gong

1 Learning objectives

After this tutorial, you should be able to:

  • state the k-means objective and show why each step of Lloyd’s algorithm cannot increase it;
  • implement Lloyd’s algorithm and k-means++ seeding and explain why multiple starts are needed;
  • choose the number of clusters with the elbow, silhouette, and gap statistic and say what each one measures;
  • interpret k-means clusters as player archetypes and identify the players that fit poorly;
  • use k-medoids (PAM) with an arbitrary dissimilarity; and
  • list the assumptions built into k-means.

2 The objective

Given nn observations 𝒙1,…,𝒙n∈ℝp\mathbf x_1,\dots,\mathbf x_n\in\mathbb R^p, k-means seeks a partition C1,…,CkC_1,\dots,C_k and centers 𝝁1,…,𝝁k\boldsymbol\mu_1,\dots,\boldsymbol\mu_k that minimize the within-cluster sum of squares,

W(C,𝝁)=∑j=1k∑i∈Cj‖𝒙i−𝝁j‖2. W(C,\boldsymbol\mu)=\sum_{j=1}^{k}\sum_{i\in C_j}\lVert\mathbf x_i-\boldsymbol\mu_j\rVert^2.

For a fixed partition the best center is the cluster mean, and WW then equals half the average squared distance between members of the same cluster:

∑i∈Cj‖𝒙i−𝒙‾j‖2=12|Cj|∑i∈Cj∑i′∈Cj‖𝒙i−𝒙i′‖2. \sum_{i\in C_j}\lVert\mathbf x_i-\bar{\mathbf x}_j\rVert^2 =\frac{1}{2|C_j|}\sum_{i\in C_j}\sum_{i'\in C_j}\lVert\mathbf x_i-\mathbf x_{i'}\rVert^2.

So k-means is a statement about pairwise Euclidean distances within clusters. Minimizing WW exactly is NP-hard; every practical algorithm finds a local optimum.

3 Lloyd’s algorithm

Lloyd’s algorithm alternates two steps from an initial set of centers.

  1. Assignment. Give each observation to its nearest center: Cj={i:j=arg⁡min⁡l‖𝒙i−𝝁l‖}C_j=\{i:\ j=\arg\min_l\lVert\mathbf x_i-\boldsymbol\mu_l\rVert\}.
  2. Update. Replace each center by the mean of its members: 𝝁j=1|Cj|∑i∈Cj𝒙i\boldsymbol\mu_j=\frac{1}{|C_j|}\sum_{i\in C_j}\mathbf x_i.

Each step minimizes WW over one set of variables with the other held fixed, so WW never increases, and because there are finitely many partitions the algorithm terminates. Where it terminates depends on where it started.

3.1 Local optima and multiple starts

starts <- bind_rows(
  lapply(1:60, function(s) data.frame(seeding = "random", within_ss = tail(lloyd_kmeans(X, 5, seed = s, init = "random")$wcss, 1))),
  lapply(1:60, function(s) data.frame(seeding = "k-means++", within_ss = tail(lloyd_kmeans(X, 5, seed = s, init = "plusplus")$wcss, 1)))
)

ggplot(starts, aes(within_ss, fill = seeding)) +
  geom_histogram(bins = 30, alpha = 0.6, position = "identity") +
  labs(x = "Within-cluster sum of squares at convergence", y = "Starts", fill = NULL) +
  theme_minimal()

Different starts end at different partitions with different objective values. The standard practice is to run many starts and keep the best, which is what the nstart argument does.

3.2 k-means++ seeding

Random seeding often places two initial centers in the same dense region. k-means++ (Arthur and Vassilvitskii, 2007) chooses the first center uniformly and each later center with probability proportional to its squared distance from the nearest center already chosen,

P(choose 𝒙i)=D(𝒙i)2∑i′D(𝒙i′)2, P(\text{choose }\mathbf x_i)=\frac{D(\mathbf x_i)^2}{\sum_{i'}D(\mathbf x_{i'})^2},

which spreads the seeds out. The expected objective after seeding alone is within a factor O(log⁡k)O(\log k) of the optimum, and Lloyd iterations from those seeds converge faster and to better solutions on average.

4 Choosing k

Three common criteria answer slightly different questions.

4.1 The elbow

Plot WkW_k, the optimized objective for each kk. It always decreases; the “elbow” is where additional clusters stop buying much.

k_values <- 1:10
within <- sapply(k_values, function(k) kmeans(X, k, nstart = 25, iter.max = 100)$tot.withinss)

4.2 The silhouette

For observation ii in cluster AA, let aia_i be its mean distance to the other members of AA and bib_i the smallest mean distance to the members of any other cluster. The silhouette width is

si=bi−aimax⁡(ai,bi)∈[−1,1]. s_i=\frac{b_i-a_i}{\max(a_i,b_i)}\in[-1,1].

Values near 1 mean the observation sits well inside its cluster, near 0 that it lies between two clusters, and below 0 that it is probably in the wrong cluster. The average silhouette over all observations scores a clustering, and the kk with the largest average is a common choice.

D <- dist(X)
silhouette_means <- sapply(2:10, function(k) {
  fit <- kmeans(X, k, nstart = 25, iter.max = 100)
  mean(silhouette(fit$cluster, D)[, "sil_width"])
})

4.3 The gap statistic

The gap statistic (Tibshirani, Walther, and Hastie, 2001) compares log⁡Wk\log W_k with its expected value under a reference distribution with no cluster structure, typically uniform over the range of each feature:

Gap⁡(k)=E*[logWk*]−log⁡Wk, \operatorname{Gap}(k)=E^{*}\!\left[\log W_k^{*}\right]-\log W_k,

where the expectation is estimated from BB reference data sets. The recommended rule chooses the smallest kk such that Gap⁡(k)≥Gap⁡(k+1)−sk+1\operatorname{Gap}(k)\ge\operatorname{Gap}(k+1)-s_{k+1}, where sk+1s_{k+1} is the standard error of the reference simulations.

set.seed(431)
gap <- clusGap(X, FUN = function(x, k) kmeans(x, k, nstart = 10, iter.max = 100), K.max = 10, B = 50)
gap_table <- as.data.frame(gap$Tab)
gap_k <- maxSE(gap_table$gap, gap_table$SE.sim, method = "firstSEmax")
criteria <- bind_rows(
  data.frame(k = k_values, value = within, criterion = "within-cluster SS"),
  data.frame(k = 2:10, value = silhouette_means, criterion = "average silhouette"),
  data.frame(k = 1:10, value = gap_table$gap, criterion = "gap statistic")
)

ggplot(criteria, aes(k, value)) +
  geom_line(color = "#03a9e6") +
  geom_point(color = "#03a9e6") +
  facet_wrap(~criterion, scales = "free_y") +
  scale_x_continuous(breaks = 1:10) +
  labs(x = "Number of clusters", y = NULL) +
  theme_minimal()
data.frame(
  criterion = c("average silhouette", "gap statistic (first SE max)"),
  chosen_k = c(which.max(silhouette_means) + 1, gap_k)
) %>%
  knitr::kable()
criterion chosen_k
average silhouette 2
gap statistic (first SE max) 3

The criteria disagree, and that is the normal outcome on data without well-separated islands. The silhouette usually favors a small kk that splits the continuum at its widest gap; the gap statistic and elbow are more generous. When the purpose is archetypes, a kk between 4 and 8 that yields interpretable, reasonably stable groups is the practical target, and Tutorial 6.6 measures the stability.

6 k-medoids

k-means requires Euclidean distance because the mean minimizes squared Euclidean deviations. k-medoids replaces the mean with a medoid, the member of the cluster with the smallest total dissimilarity to the others, and minimizes

∑j=1k∑i∈Cjd(𝒙i,𝒎j), \sum_{j=1}^{k}\sum_{i\in C_j}d(\mathbf x_i,\mathbf m_j),

where 𝒎j\mathbf m_j is an actual observation. Because only dissimilarities between observations are needed, any distance from Tutorial 6.1 can be used, and because the objective sums distances rather than squared distances, outliers pull less. The standard algorithm is Partitioning Around Medoids (PAM), which swaps medoids with non-medoids while the objective improves.

pam_fit <- pam(dist(X, method = "manhattan"), k = k)

data.frame(
  cluster = seq_len(k),
  medoid = rownames(X)[pam_fit$id.med],
  size = as.numeric(table(pam_fit$clustering))
) %>%

The adjusted Rand index, defined in Tutorial 6.6, is 1 for identical partitions and about 0 for unrelated ones. The two methods agree on much of the structure and differ at the boundaries, which is where the choice of distance matters.

7 What k-means assumes

  • Clusters are spherical and similar in size in the standardized space, because every observation goes to the nearest center by Euclidean distance.
  • Every observation belongs to exactly one cluster, with no notion of uncertainty or of outliers.
  • kk is known. The algorithm has no internal reason to prefer one kk over another.
  • The scale of the features is meaningful, so standardization and weighting decide the result.

Each of the next three tutorials relaxes one of these: hierarchical clustering removes the fixed kk, mixture models add elongated clusters and soft membership, and density-based methods add outliers and arbitrary shapes.

8 Practice

  1. Show that for a fixed cluster the mean minimizes ∑i∈C‖𝒙i−𝝁‖2\sum_{i\in C}\lVert\mathbf x_i-\boldsymbol\mu\rVert^2 over 𝝁\boldsymbol\mu.
  2. Why does the within-cluster sum of squares always decrease with kk, and why does that make it unusable on its own for choosing kk?
  3. An observation has ai=2a_i=2 and bi=3b_i=3. What is its silhouette, and how would you describe its position?
  4. Give one situation in which PAM is preferable to k-means.
TipShow answers
  1. The gradient with respect to 𝝁\boldsymbol\mu is −2∑i∈C(𝒙i−𝝁)-2\sum_{i\in C}(\mathbf x_i-\boldsymbol\mu), which is zero only at the cluster mean, and the objective is convex in 𝝁\boldsymbol\mu.
  2. With k+1k+1 clusters one can always reproduce the best kk-cluster solution and split one cluster, which cannot increase the objective; a criterion that always improves cannot select a value.
  3. si=(3−2)/3=0.33s_i=(3-2)/3=0.33: inside its cluster but not far from the next one.
  4. When the dissimilarity is not Euclidean (Manhattan, Gower, correlation), when outliers are present, or when an interpretable representative observation is wanted for each cluster.

9 Key takeaways

  • k-means minimizes within-cluster squared Euclidean distance; Lloyd’s algorithm finds a local optimum, so use many starts and k-means++ seeding.
  • The elbow, silhouette, and gap statistic measure different things and often disagree; choose kk for the purpose.
  • Cluster centers in z-score units are the primary tool for naming archetypes; silhouettes identify the players that fit poorly.
  • k-medoids works with any dissimilarity and returns real players as representatives.
