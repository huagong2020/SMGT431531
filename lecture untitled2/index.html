Using the materials

Open the tutorials in a modern browser. Use the left and right arrow keys to navigate slides and press S for presenter notes. Editable sources are the .qmd files in each lecture folder. Each lecture contains R/guided_lab.R, local data, and scripts for rebuilding examples.

The README explains setup and rendering. The teaching guide identifies a core classroom route and optional extensions.

Course connection

These units continue Lectures 1–3 using the same Quarto tutorial and Reveal.js slide format. The player and team modeling sequence draws inspiration from Ron Yurko's Statistical Thinking in Sports Analytics. Technical references and dataset provenance appear with the tutorials.

Historical sports examples use the documented datasets. Simulations are labeled in their tutorials. Ratings and groups describe the stated sample and model assumptions.
