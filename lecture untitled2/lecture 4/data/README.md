# Player evaluation teaching data

All files are generated by scripts in `R/` and stored locally so the website
renders offline.

## `nfl_passes_2023.rds`

Generated by `R/prepare_player_data.R` from 2023 regular-season play-by-play
data distributed through [`nflreadr`](https://nflreadr.nflverse.com/).

| Field | Value |
|:--|:--|
| Provider | nflverse play-by-play via nflreadr |
| Season | 2023 regular season |
| Unit | one pass attempt |
| Attempts | 17,483 |
| Passers / receivers / defenses | 102 / 482 / 32 |

The object is a list with `passes` (a data frame) and `provenance`. Filters:
`play_type == "pass"`, no sacks, spikes, scrambles, or two-point attempts, and
non-missing air yards, pass location, passer, receiver, completion flag, and
`qb_epa`. Player names and positions come from `nflreadr::load_rosters(2023)`.
The columns `nflverse_cp` and `nflverse_cpoe` are the completion probability and
CPOE shipped with the play-by-play data; the tutorials build their own versions.

## `wnba_2024.rds`

Generated by the same script from 2024 regular-season box scores distributed
through [`wehoop`](https://wehoop.sportsdataverse.org/). `clark_games` is
Caitlin Clark's game-by-game shooting log ordered by date. `league_three` holds
season three-point makes and attempts for every player with at least 40
attempts.

## `bayes_results.rds`

Generated by `R/build_bayes_results.R`. Contains:

- `lme4`: variance components, fixed effects, and passer random effects from
  the crossed EPA and completion models;
- `bootstrap`: 200 parametric-bootstrap replicates of the EPA model's standard
  deviations and passer effects (`bootMer`, `use.u = FALSE`);
- `stan`: posterior summaries, passer and defense effect draws, and sampler
  diagnostics from `R/completion_multilevel.stan` fitted with CmdStan (4 chains,
  1,000 warmup and 1,000 sampling iterations each).
