# NBA clustering teaching data

`nba_2024.rds` is generated by `R/prepare_nba_data.R` from ESPN box scores and
play-by-play for the 2023-24 NBA regular season distributed through
[`hoopR`](https://hoopr.sportsdataverse.org/). The object is a list with three
components and a `provenance` record.

## `profiles`

One row per player with at least 500 regular-season minutes (360 players).
Columns include season totals (`points`, `fga`, `fg3a`, `fta`, `oreb`, `dreb`,
`ast`, `stl`, `blk`, `tov`, `pf`), per-36-minute rates (`pts_36`, ...,
`pf_36`), shooting shares and efficiencies (`three_rate`, `ft_rate`, `efg`,
`ts`, `ast_to_tov`), the listed `position` and a `position_group` (Guard,
Forward, Center), and the player's most frequent `team`. The position fields
are kept only as external references for validation.

## `shots`

One row per field-goal attempt (219,105 attempts by 568 shooters). Free throws
are excluded. ESPN's full-court coordinates are folded onto one half court:
`court_y` is the distance from the basket toward midcourt and `court_x` the
left-right offset when facing the basket, both in feet. `distance` is the
straight-line distance to the basket, `made` and `points` record the result,
`three` flags three-point attempts, and `shot_type` is ESPN's play type label.

## `shooter_counts`

Attempts per shooter, used to select players with enough shots for shot-chart
factorization.

## Attribution

Cite ESPN and hoopR as the data providers, not this course file. The data are
intended for instruction rather than production modeling.
