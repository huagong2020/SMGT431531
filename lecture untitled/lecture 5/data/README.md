# Team evaluation teaching data

All files are generated by scripts in `R/` and stored locally so the website
renders offline.

## `nfl_games.rds`

Generated by `R/prepare_team_data.R` from the schedule and results data
distributed through [`nflreadr`](https://nflreadr.nflverse.com/).

| Field | Value |
|:--|:--|
| Provider | nflverse schedules via nflreadr |
| Seasons | 2022, 2023, 2024 regular seasons |
| Unit | one game |
| Games | 815 (one 2022 game was canceled) |
| Ties | 2 (both in 2022) |
| Neutral-site games | 16 (international games) |

The object is a list with `games`, `teams`, and `provenance`. `margin` is the
home score minus the away score. `spread_line` is the closing spread with a
positive value meaning the home team was favored; `home_moneyline` and
`away_moneyline` are American odds.

## `epl_matches.rds`

Generated by the same script from the E0 files at
[football-data.co.uk](https://www.football-data.co.uk/) for the 2021-22,
2022-23, and 2023-24 Premier League seasons (380 matches each). Includes goals,
shots, shots on target, and closing Bet365 decimal odds.

## `team_results.rds`

Generated by `R/build_team_results.R`. Contains:

- `poisson`: posterior draws (4,000) of the intercept, home effect, attack and
  defense effects, and variance components from the `rstanarm` multilevel
  Poisson model for 2023-24, plus 500 posterior predictive replications of the
  season and the data in long form;
- `state_space`: posterior summaries of the hyperparameters and every team-week
  strength, draws of the final-period strengths, and sampler diagnostics from
  `R/dynamic_ratings.stan` fitted with CmdStan (4 chains, 1,000 warmup and
  1,000 sampling iterations each).
